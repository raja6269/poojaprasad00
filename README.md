# POOJAPRASAD — Online Pooja & Chadawa Platform

A website for booking online temple poojas, weekly chadawa, and doorstep Prasad delivery.

## Features
* **Daily Panchang & 7-Day Chadawa Schedule**
* **Razorpay Payment Integration**
* **Automated WhatsApp Booking Redirect**
* **Embedded Admin CRM Panel** (Passcode: `admin123`)
* **CSV Lead Exporting**

## Deployment Steps
1. Push this directory to your GitHub repository.
2. Link the repository to your Vercel Dashboard.
3. Vercel will automatically build and deploy the site.
